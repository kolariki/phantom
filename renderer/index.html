¿Cómo obtengo una API Key?
  1. Entrá a console.anthropic.com
  2. Creá una cuenta o inicia sesión.
  3. En "API Keys" → "Create Key".
  4. Copiá la clave y pegala arriba.
  5. Cargá saldo en "Billing" (mínimo $5).
¿Cómo obtengo una API Key?
  1. Entrá a platform.openai.com
  2. Creá una cuenta o inicia sesión.
  3. Click "Create new secret key".
  4. Copiá la clave y pegala arriba.
  5. Cargá saldo en "Billing" (mínimo $5).
